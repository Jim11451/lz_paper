## 补充：两个"为什么没有"的问题

**为什么没有 $gg\to g^*\to t\bar tV$？**

1. **图层面**：MG5 对 `g g > t t~ vb` 给出 8 张图，其中 **2 张是 $s$-channel 胶子**
   （$gg\to g^*\to t\bar t$，$V$ 从 $t$ 或 $\bar t$ 发出，diagram 1/2，内线是卷曲的胶子），
   另外 6 张是 $t$-channel（两个胶子接在 top 线两个不同点，$V$ 从外线或内线发出）。
   没有 $g\,t\bar t\,V$ 接触顶点，也没有 $ggt\bar t$ 顶点。
2. **数值层面**：MG5 跑 `g g > g` 给出

```
Survey return zero cross section.
   Typical reasons are the following:
   1) A massive s-channel particle has a width set to zero.
   2) The pdf are zero for at least one of the initial state particles
      or you are using maxjetflavor=4 for initial state b:s.
   3) The cuts are too strong.
```

   真实原因是第 2 条：$g g\to g$ 三个粒子都无质量，$\sqrt{\hat s}=0$ 要求 $x_1=x_2=0$，
   PDF 在此处为零，积分恒等于零。对照实验：`u u~ > a`（同样无质量 2→1）也是零，
   `u u~ > z`（末态有质量 $m_Z=91.2$ GeV）给 9206 pb。

   （注：早先"色因子 $f^{abc}$ 反对称 ⇒ 振幅恒为零"的说法**不成立**：$8\otimes8$ 含 8，
   颜色并不禁止 $gg\to g$；真正的限制是运动学。）

**为什么没有 $q\bar q\to V^*\to t\bar tV$？**

这张图拓扑上合法（模型同时有 $Vq\bar q$ 与 $Vt\bar t$ 顶点），MG5 也确实能生成它——问题出在**模型建立时给
PDB 阶设的上限**：

```
WARNING: The coupling order (PDB=3) specified is larger than the one allowed
         by the model builder. The maximal value allowed is 2.
```

这四张图需要 3 个 PDB 顶点（$Vq\bar q$ + $Vt\bar t$ + 发射的 $Vt\bar t$），而上限是 2，所以被截掉。
把同一份 UFO 的 7 个 `order = {'PDB':1}` 改成 `{'QED':1}`（只改阶数标签、不改耦合值）后，
同一个进程立刻从 12 张变成 16 张，$V$ 作为内线出现 4 次——MG5 没有 bug，是 UFO 的阶数声明卡住了它。

量级：以 $M_V=100$、$u\bar u$、**产生层面（不含衰变）**为例
- QCD 图（4 张）：$\sigma=0.095901$ pb
- 纯 EW（$\gamma^*/Z^*/V^*$ 交换，12 张）：$\sigma=9.6232\times10^{-4}$ pb = QCD 的 **1.00%**
- 其中 $V^*$ 那 4 张按 $(g_{Vq}/e)^2=1.78\times10^{-9}$ 再压低 ⇒ 对总截面贡献 $\sim1.7\times10^{-11}$

（注：把 7 个 `order` 从 PDB 改标为 QED 后，同一 QCD 过程给出 0.095901 pb，
与原模型逐位相同，说明改标签不动任何耦合值。）

所以 $s$-channel 不能按份额相加：它单独存在时是 0.66 pb，加进来却把总截面压低 1.06 pb（$-14.8\%$）。
删掉 #1/#2 会把 $gg$ 高估 17.4%。
