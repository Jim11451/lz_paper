# Step 5.4.1 — micrOMEGAs 中介子宽度交叉验证

## 1. micrOMEGAs 如何算这个宽度

模型文件 `PDmq/work/models/prtcls1.mdl` 第 21 行：

```
baryon vector|V|V|9900032|2|MV|!wV|1|G|V|V
```

- 中介子在 CalcHEP 里的名字是 **`V`**（不是 UFO 的 `Vb`），PDG **9900032**，质量参数 `MV`；
- 宽度参数写作 **`!wV`**，感叹号表示**自动宽度**：CalcHEP 从模型顶点自己算，不读外部输入。

官方接口（`include/micromegas.h`）：

```c
extern double pWidth(const char *name, txtList *L);          // line 159
extern void printPartialWidth(double width, txtList l, int p, FILE *f);  // line 136
```

`printPartialWidth` 的第三个参数是**打印精度**（`%.*E`，见 `sources/higgsmass.c:22`）。`main.c` 里用 `p=2`，只有 3 位有效数字；本核查用 `p=8`，才有 8 位。

为此写了独立驱动 `PDmq/width_drv.c`（不改动 `main.c`、`lz_recoil*.c`）：

```c
readVar(argv[1]); sortOddParticles(cdmName);
double w = pWidth("V", &L);
printf("WIDTH_V_TOTAL %.8e\n", w);
printPartialWidth(w, L, 8, stdout);
```

编译：`make main=width_drv.c`（与 `lz_recoil` 同一套 Makefile）。

## 2. 对比方法

- 解析侧：`STEP53_CHECKS.md` 的公式，**在本脚本里用全精度重算**（不复用 `widths_v2.csv` 的舍入列——那里 $G_q$ 由两个大数相减得到，$G_q\ll G_{\rm tot}$ 时会有 20% 量级的抵消误差，第一版对比就被它坑过）；
- 暗顶点 $-g_\chi/2$，末态 $\chi_1\ne\chi_2$（无全同因子）；
- 夸克：$N_c=3$，$g_{Vq}=g_t m_q/172$，$\beta_q=\sqrt{1-4m_q^2/M_V^2}$；
- **先比树级**（把我们的 $1+\alpha_s/\pi$ 除掉），再单独报告 QCD 修正。

## 5. 差异归因

| 候选原因 | 结论 |
|---|---|
| 耦合归一（$g_\chi/2$） | **无问题**：$\Gamma_\chi$ 与 micro 一致到 $4\times10^{-7}$ |
| 多/少一个 2 | **无**：若有，$\Gamma_\chi$ 会差 2 或 4 倍 |
| 全同粒子因子 | **无**：$\chi_1\ne\chi_2$，未加 $1/2$，与 micro 一致 |
| 颜色因子 | **无**：$\delta_{c},\delta_{b}$ 在 $10^{-5}$–$10^{-4}$，若有 $N_c$ 错误会差 3 倍 |
| 不等质量相空间 | **无问题**：$\Gamma_\chi$ 用 $\beta_\chi^2=1-(m_1+m_2)^2/M_V^2$，与 micro 的精确二体一致到 $10^{-7}$ |
| 夸克质量/阈值 | **残差来源**：$\delta_s$、$\delta_b$ 最大（$10^{-3}$），是 $\beta_q$ 对 $m_s,m_b$ 取值的敏感（我们用 0.093/4.18，模型内部取值略有差别） |
| QCD 修正 | **唯一系统性差异**：我们乘 $1+\alpha_s/\pi=1.038$，micro 是树级 |

$\Gamma_{\rm tot}$ 的树级残差随 $M_V$ 单调减小（$M_V$=30 时 $7\times10^{-4}$，$M_V\ge160$ 时 $<10^{-8}$），正是因为低 $M_V$ 时夸克道占比大、$\beta_q$ 对质量敏感。

## 6. 对物理结果的影响

1. **遗迹丰度完全不受影响**：$\Omega h^2$ 由 micrOMEGAs 自己用内部（树级）宽度计算，我们的 $1+\alpha_s/\pi$ 从未进入求根链路。宽度只通过传播子进入 $\Omega$，在有效点 $\Gamma/M\le3\%$ 时影响 $\lesssim10^{-3}$。
2. **排除图里的 BR$_{\rm inv}$** 用的是含 QCD 的值，比 micro 低：有效点上最大 **1.8%**（$M_V$=120、$g_t$=3：0.5224 vs 0.5130），中位数 0.3%。信号产额与 $\mu_{95}$ 同比例变化 ≤1.8%，**小于效率系统不确定度 2.7%**。
3. **$\Gamma/M$ 判据**：我们的值在夸克主导点上大 3.8%，不影响任何有效性标记（最紧的点距 3% 阈值仍有余量）。

## 7. 建议

**保持现状，不改冻结结果。** 理由：

- 树级一致到 $2\times10^{-5}$（有效点），说明耦合、颜色、相空间全部正确；
- 唯一差异是我们主动加的 NLO QCD 因子，物理上更准，且对 $\mu_{95}$ 的影响（≤1.8%）被效率系统误差（2.7%）覆盖；
- 若要"与 micrOMEGAs 严格同口径"，最小改动是在 `widths_v2` 里把 NLO 因子设为 1（一行），但这会让 BR 偏离 NLO 物理值，且需要重跑 5.4 网格——**在没有新证据前不建议**。

论文中应写一句：BR$_{\rm inv}$ 用 NLO 宽度（含 $1+\alpha_s/\pi$），与 micrOMEGAs 内部树级宽度的差异在有效点上 ≤1.8%。

## 8. 局限

- micro 的通道宽度只能通过 `printPartialWidth` 取，精度受打印参数限制（本核查用 8 位，足够）；
- micro 是树级，本核查的"QCD 差异"不是错误，而是口径；
- 相空间的夸克质量用 pole 近似，$\delta_s/\delta_b\sim10^{-3}$ 的残差即来源于此，未进一步追到模型内部的质量表。

## 11. 效率不确定度的来源（澄清）

两个数字容易混，必须分清：

| 测量 | 选择 | $R_\varepsilon$ | 是否采用 |
|---|---|---|---|
| 代理判据 | 仅 $\mathrm{MET}>250$ | $0.97975\pm0.01281$（$1.6\sigma$） | ❌ 作废 |
| **真实 SR 选择** | 无轻子 + $n_j\ge3$ + $n_b\ge2$ + $\mathrm{MET}>250$ | $\mathbf{0.9722\pm0.0273}$（$1.0\sigma$） | ✅ **采用** |

- 代理判据的通过数约多 3 倍，误差被低估，所以 $1.6\sigma$ 不可信，已作废；
- 采用值 $R_\varepsilon=0.9722$ 与 1 只差 $1.0\sigma$，**不改中心值**（不乘 0.972）；
- 因此"$\pm2.7\%$"= 真实选择的 **$\delta\bar R_\varepsilon$**，它不是探测器系统误差，而是**两个有限 MC 样本之比的统计误差**；探测器/选择的共同乘性偏差在比值中相消，不含在内；
- 5.4 报告里写作"±2%"，是这笔数的四舍五入；**严格值 2.7%**，论文与最终表应统一用 2.7%。

**不与宽度误差重复计入**：两者是不同来源，各自线性传播到 $\mu_{95}$——

| 来源 | 对 $\mu_{95}$ 的影响 |
|---|---|
| 效率比 $R_\varepsilon$ | $\pm2.7\%$ |
| BR$_{\rm inv}$（NLO vs 树级） | $\le1.8\%$（有效点），中位 0.3% |

合成为 $\sqrt{2.7^2+1.8^2}=3.2\%$（若按独立处理）；它们**不是**同一个误差的两次计入，也不与背景系统误差（3.2% 相干宽度）相加——后者作用在 $b$ 上，与信号归一化正交。
