## 检查 1：$\Gamma(V\to\chi_1\chi_2)$ 是否适用于实际模型

### 1.1 顶点

UFO `PseudoDiracFlavorEFT_UFO_loop/vertices.py`：

```
V_PDB_chiV = Vertex(particles=[P.chi1, P.chi2, P.Vb], lorentz=[L.FFV1],
                    couplings={(0,0): C.GC_PDB_2})
GC_PDB_2 = -gChi/2
```

- **纯矢量** `FFV1`，不是手征流；
- 耦合确实是 $-g_\chi/2$；
- $\chi_1$ 与 $\chi_2$ **是不同粒子**（$m_2=m_1+1$ MeV），因此**没有**全同粒子的 $1/2$ 对称因子。宽度里的 $1/2$ 只来自耦合本身的 $g_\chi/2$，不是对称因子——这一点在下面推导里显式体现。

### 1.2 推导（不假设末态等质量）

$M=g\,\varepsilon_\mu\,\bar u_1\gamma^\mu v_2$，$g=g_\chi/2$。自旋求和（$v_2$ 满足 $(\not p_2+m_2)v_2=0$，故传播子取 $\not p_2-m_2$）：

$$\mathrm{Tr}\left[(\not p_1+m_1)\gamma^\mu(\not p_2-m_2)\gamma^\nu\right]
=4\left[p_1^\mu p_2^\nu+p_1^\nu p_2^\mu-g^{\mu\nu}(p_1\!\cdot\!p_2+m_1m_2)\right]$$

与极化求和 $-g_{\mu\nu}+k_\mu k_\nu/M^2$ 缩并：

$$\sum_{\rm pol,spin}|M|^2=4g^2\left[(p_1\!\cdot\!p_2)+\frac{2(k\!\cdot\!p_1)(k\!\cdot\!p_2)}{M^2}+3m_1m_2\right]$$

$$\Gamma=\frac{1}{3}\cdot\frac{|\vec p|}{8\pi M^2}\sum|M|^2
=\frac{|\vec p|\,g^2}{6\pi M^2}\left[(p_1\!\cdot\!p_2)+\frac{2(k\!\cdot\!p_1)(k\!\cdot\!p_2)}{M^2}+3m_1m_2\right]$$

$1/3$ 是**初态矢量介子三个极化态的平均**（容易漏，漏了就得到偏大 3 倍的结果）。

两个极限检验：

| 极限 | 上式 | 标准结果 |
|---|---|---|
| $m_1=m_2=0$ | $g^2M/12\pi$ | $\checkmark$ 教科书值 |
| $m_1=m_2=m$ | $g^2M\beta(3-\beta^2)/12\pi$ | $\checkmark$ 与表中公式相同 |

### 1.3 等质量近似 vs 完整相空间（70 点实测）

$m_2=m_1+1$ MeV 时，完整 $\lambda^{1/2}$ 公式与等质量公式的最大相对差：

$$\max\left|\frac{\Gamma_{\rm exact}-\Gamma_{\rm equal}}{\Gamma_{\rm equal}}\right|=2.3\times10^{-4}$$

（$M_V$=60：$3.4\times10^{-5}$；100：$1.2\times10^{-5}$；200：$8.5\times10^{-7}$）

**结论**：公式适用；$m_1\ne m_2$ 的影响可忽略；无全同粒子因子。

## 检查 2：5.2 的求根是否受 3 倍错误影响

**没有。**

1. **求根时传给 micrOMEGAs 的参数卡里没有任何宽度**（`PDmq/b2_w*.par` 全文）：

```
Mchi / dM / MV / gChi / gVu..gVt / fExc / rho0 / v0 / vE / vesc
```

2. $\Gamma_V$ 由 micrOMEGAs 从模型顶点内部计算（输出里 `VWdecay=1`），**从未读入我的解析公式**。那个 3 倍错误只出现在 `STEP52_VALIDITY2.md` 的**筛选表**里，不影响 `band_v2.csv` 的任何丰度根。

3. 所以"不重算 5.2"的理由不是"标记集合没变"，而是**错误的量根本没进求根链路**。

4. **必须如实说明的一点**：我们**没有**直接验证 micrOMEGAs 内部的 $\Gamma_V$ 与 5.3 的数值一致（该程序没有输出宽度的接口，`VWdecay` 也不是可覆盖参数）。可以界定它的影响：
   - 丰度只通过传播子 $\propto 1/[(M_V^2-s)^2+\Gamma^2M_V^2]$ 依赖宽度；
   - 33 个合格点满足 $\Gamma/M\le3\%$，且 $M_V^2-s=M_V^2\beta^2$，故修正量 $\lesssim(\Gamma/M)^2/\beta^4\lesssim10^{-3}$；
   - 宽度真正重要的 7 个点在 5.2 已被标记为模板不合格。

### 4.4 BR_inv 对应的衰变道

`BRinv = Γ(V(9900032) → χ1(100051) + χ2(100052))/Γ_tot`，即**中介子直接衰变到暗态对**，末态在探测器里不可见——这正是 tt̄+MET 与单喷注信号所依赖的"不可见分支比"。
