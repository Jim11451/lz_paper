# External software and public data

The model UFO includes Standard Model and loop-SM components generated for MadGraph. Their existing source headers and copyright notices are retained. micrOMEGAs, CalcHEP, MadGraph5_aMC@NLO, Pythia8, Delphes, ROOT and PDF libraries are external dependencies, governed by their respective licenses and citation requirements. The complete installed distributions and compiler binaries are outside this archive.

The public CMS numerical inputs originate from HEPData record 106115 version 2, DOI `10.17182/hepdata.106115.v2`, and the cited CMS publications. Preserve the HEPData attribution when redistributing the tables. The original downloaded CSV archive is stored under `tmp/` and included in the integrity manifest.

The ttbar supplemental source files are copied from the collaborator-provided analysis package. Their source comments and validation scope are preserved. The repository carries no additional blanket license grant over third-party or collaboration-owned material. A collaboration-approved software license can be added separately.

Historical scripts contain the original installation paths for provenance. Portable entry points use explicit local installation arguments and require no CERN membership or private workstation account for the offline calculation.
