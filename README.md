# LZ 高能核反冲与伪 Dirac 暗物质唯象

本文研究一个质量加权矢量中介子模型，比较 LZ 高能核反冲参考率、Planck 热丰度条件和 CMS monojet 搜索的灵敏度。当前版本包含三个 monojet 代表点的独立模板检验及对顶夸克伴随产生的复核。
